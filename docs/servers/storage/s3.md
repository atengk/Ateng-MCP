# S3 对象存储 MCP 服务

<div style="display: flex; gap: 8px; flex-wrap: wrap; margin: 16px 0;">
  <VpBadge type="tip">生产级</VpBadge>
  <VpBadge type="info">FastMCP / Python 3.11</VpBadge>
  <VpBadge type="purple">Stdio & SSE</VpBadge>
  <VpBadge type="warning" dot>工单建设中</VpBadge>
</div>

面向标准 AWS S3 及兼容协议（如 MinIO、Ceph、Cloudflare R2 等）的对象存储智能管理与审计服务。基于 Model Context Protocol (MCP) 为大模型与自主智能体（Agent）赋予存储桶生命周期治理、ACL 权限巡检、预签名链接安全生成及大文件批量操作等能力。

---

## 1. 核心定位与技术架构

- **服务定位**：多云与私有化对象存储的统一智能交互中枢；
- **技术栈**：Python 3.11+、FastMCP 框架、boto3 SDK；
- **通信模式**：支持标准输入输出（Stdio）与远程 HTTP/SSE；
- **安全审计**：敏感文件访问审计、公有读写 Bucket 泄露风险告警。

---

## 2. 规划能力与工具矩阵

> [!NOTE] 模块演进计划
> 本服务端正在进行规范化重构（对应工单 #15），预计提供以下核心 Tool / Resource 能力。

| 工具名称 | 分类 | 说明 | 风险等级 |
| :--- | :--- | :--- | :--- |
| `s3_list_buckets` | 存储总览 | 列出全部可用 Bucket 及容量配额、区域分布 | 只读 (Readonly) |
| `s3_bucket_security_audit` | 安全合规 | 检查 Bucket 是否意外开启公共读写（Public Access） | 只读 (Readonly) |
| `s3_search_objects` | 内容检索 | 支持前缀匹配、标签过滤与分页检索对象元数据 | 只读 (Readonly) |
| `s3_generate_presigned_url`| 安全访问 | 为指定对象生成临时有时效的预签名下载/上传链接 | 受控 (Guarded) |
| `s3_batch_delete_objects` | 生命周期 | 批量清理符合规则的临时或归档对象 | 高危 (Sensitive) |

## 3. 客户端快速挂载预览

参考 [多客户端统一接入指南](../../guide/client-setup.md) 进行本地或容器化配置：

```json
{
  "mcpServers": {
    "s3-mcp": {
      "command": "uvx",
      "args": ["ateng-s3-mcp"],
      "env": {
        "AWS_ENDPOINT_URL": "http://minio.internal:9000",
        "AWS_ACCESS_KEY_ID": "admin",
        "AWS_SECRET_ACCESS_KEY": "${SERVICE_PASSWORD}",
        "AWS_REGION": "us-east-1"
      }
    }
  }
}
```
