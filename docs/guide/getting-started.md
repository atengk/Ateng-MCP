# 欢迎使用 Ateng MCP 文档中心

这是面向大模型与 Agent 生态的现代化 **Model Context Protocol (MCP)** 生产级服务端矩阵官方文档中心。

---

## 1. 核心概述

Ateng MCP 矩阵提供了涵盖消息队列（RocketMQ、Kafka、RabbitMQ）、云原生运维（Kubernetes）、存储（S3）与通信工具（Email）等多个领域的生产级 MCP 服务端实现。

每个服务端均具备严格的权限防灾、标准化 Stdio/SSE 通信支持以及详尽的工具契约。您可以在此查阅各服务端的使用指南、客户端挂载配置与架构设计。

您可以直接在此目录下编辑 Markdown 文档，或者创建新的子目录以构建分层分类体系。

---
